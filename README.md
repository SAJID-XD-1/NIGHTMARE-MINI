## 🕷️ The Nightmare Philosophy

NIGHTMARE-MINI is a lightweight WhatsApp automation project built around simplicity, customization, and a modular plugin system.

Designed to keep things powerful without making them complicated.

> **"Don't follow the system. Build one that follows your vision."**

## ⚡ Core Identity

- 🕸️ **Modular Architecture** — Flexible commands and plugins.
- 🖤 **Minimal Design** — Lightweight, clean, and customizable.
- 🔗 **Pairing Dashboard** — A modern web interface for WhatsApp pairing.
- 💾 **Session Persistence** — Designed for reliable session management.
- 🚀 **Built to Evolve** — A foundation for future features and improvements.
